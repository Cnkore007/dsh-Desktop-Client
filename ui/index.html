官方命令参考（中文）

以下为官方 dsh 命令行帮助的中文对照（来自打包的官方运行时，桌面客户端不改动任何官方源码）。

dsh —— 启动 DeepSeek Harness 档案（profile）

用法: dsh [选项] [命令] [参数...]

选项:
  -V, --version         输出版本号
  --profile <名称>      要启动的档案（位于 $DSH_HOME/profiles 下）
  --patch <路径>        追加的补丁覆盖层（可重复）
  --dump-config         打印合成后的档案树并退出
  --dump-default-config 打印不含用户层的档案树并退出

命令:
  web     启动 web 档案（即 --profile web 的别名）；web 自身的参数在其后
  plugin  管理档案的插件（把剩余参数转发给档案目录中的 pnpm）

dsh web —— 启动 Web 服务（本桌面客户端使用）

用法: dsh --profile web [选项]

选项:
  --host <主机>       绑定主机地址（0.0.0.0 被官方有意禁用，防止网络暴露）
  --port <端口>       监听端口；传 0 由系统分配空闲端口
  --trusted-host <主机:端口...>  额外加入 /api 浏览器信任围栏的地址（可重复）
  -h, --help          显示帮助

示例:
  dsh --profile web                在默认主机与端口上提供服务
  dsh --profile web --port 8080    在其他端口提供服务

常见用法

dsh --profile headless "运行一个任务"   回答一个任务并退出（无界面）
dsh --profile tui                       启动终端界面档案
dsh --profile web --help                查看 web 档案的完整参数
dsh plugin --profile tui add <包名>     向档案安装插件

数据目录：$DSH_HOME（未设置时为 ~/.dsh），与官方 CLI 完全兼容。
